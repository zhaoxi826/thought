确实有问题。fusion.rs 里截断阈值是 max(min_score, 首条 × relative_cutoff)，当首条分数异常高时（比如精确命中了标题），relative_cutoff 会把语义相近但分数不到一半的结果全部砍掉。

示意修复——首条为离群值时，退回用中位数做基准：

symbol/src/fusion.rsrust
1let baseline = if is_outlier(scores[0], &scores[1..]) {
2    // 首条是离群值：改用中位数基准
3    median(&scores)
4} else {
5    scores[0]
6};
7let cutoff = min_score.max(baseline * self.relative_cutoff);
8hits.retain(|h| h.score >= cutoff);
建议 离群判定可以用「首条 > 中位数 × 2」这种简单规则；另外建议给 relative_cutoff 配一个绝对下限，避免基准本身过低时误保留噪声。
