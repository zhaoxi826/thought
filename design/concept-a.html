确实有问题。fusion.rs 里截断阈值是 max(min_score, 首条 × relative_cutoff)，当首条分数异常高时（比如精确命中了标题），relative_cutoff 会把语义相近但分数不到一半的结果全部砍掉。

symbol/src/fusion.rs — 示意修复
// 首条为离群值时，退回用中位数做基准 let base = if is_outlier(first, &scores) { median(&scores) } else { first.score }; let cutoff = min_score.max(base * relative_cutoff); results.retain(|r| r.score >= cutoff);
建议 首条为离群值时退回用中位数做基准，避免单个精确命中抬高档位、误伤整批语义相近的结果。
