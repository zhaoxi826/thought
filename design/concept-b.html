THOUGHT · 14:03

确实有问题。fusion.rs 里截断阈值是 max(min_score, 首条 × relative_cutoff)：当首条分数异常高时（比如精确命中了标题），relative_cutoff 会把语义相近但分数不到一半的结果全部砍掉。

改动很小，只在计算基准分时做一次离群判断：

rustsymbol/src/fusion.rs
let baseline = if is_outlier(first.score, &scores) {
    median(&scores)          // 首条离群时退回中位数
} else {
    first.score
};
let cutoff = min_score.max(baseline * relative_cutoff);
results.retain(|r| r.score >= cutoff);
建议 首条为离群值时退回用中位数做基准，避免单个精确命中抬高整个截断线；离群判断可以用首条分数 > 中位数 × 2 这种简单规则起步。
